# Calc

Calc is a console calculator

# Supported

Integer arithmetic

# Usage

## Argument Mode

argument mode solves the problem provided and outputs the result

to use it: do this

```
calc PROBLEM
```

an example here:

```
calc 5 + 5
```

or

```
calc "81 - 11"
```

## Interactive mode

interactive mode give you a REPL interface for calculating

to use it: do this

```
calc
```

to quit: type `quit`
