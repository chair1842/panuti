# Licenses

There are 9 projects/components inside panuti.
- kernel
- libc
- pint
- pur
- pcrutils
- nib
- calc
- conway
- fstools

There are 2 third-party components
- uACPI (kernel)
- eyalroz/printf (libc)

Each of these projects/components have their own individual licenses,
and have a LICENSE.md at their top-level directory. Vendored third-party
components ship their upstream license file instead.
