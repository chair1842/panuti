# PCrUtils

**Panuti Core Utils**

This project is a set of small and composable utilities that have various uses

These utilities will not have GNU/POSIX compliance as an assurance

## utility list

echo in pwd tsb ls sleep clear cat mul cbi grep wc tail head split nexist stat mkdir mount umount
sort uniq cut tr rev tac nl paste join comm seq printf yes od out rm mv ln find du touch tee cp
truncate basename dirname cmp fold cksum

this list can also be accessed by typing pcrutils in the terminal
